# Unity 操作與驗證紀錄

作業日期 2026-11-13。使用 Unity 6000.4.11f1（Built-in Render Pipeline、Gamma 色彩空間），Blender 5.2.3 LTS，FFmpeg。

## 製作步驟

1. 由參考專案取得 Unity 設定、森林素材與 Editor 腳本，作為骨架（fac9099）。
2. 用 Blender 程序化建出暴龍（bb85b39）：
   - 軀幹、尾、頭、下顎以超橢圓斷面放樣；腿、臂以 Skin modifier 建成，牙與爪是圓錐。
   - 依骨段距離計算權重，產生 4 段動作。
   - 以 Cycles 烘焙皮膚的 albedo 與法線貼圖。
   - 匯出 FBX 後，在乾淨場景重新匯入驗證。
3. Unity 場景與渲染腳本改寫為 T-Rex 版（c30f0f7，Haiku 實作）。之後由獨立審查員（Sonnet）唯讀審查，回報 2 項 MEDIUM 與數項 LOW 問題。
4. Unity 實測中修正了以下三項：
   - **材質重映射遺失**：建材質時匯入貼圖會刷新 AssetDatabase，使先前排入 `ModelImporter` 的 remap 被丟棄（參考專案只有 1 個材質槽，所以沒有踩到）。改為先建好全部材質，再一次設定 importer。
   - **蒙皮不更新**：Unity 6000.4 批次擷取時，`SampleAnimation` 之後蒙皮矩陣不會重算，吼叫畫面顯示的是靜止姿勢。診斷時連續 `Camera.Render` 的輸出逐格相同，但 `BakeMesh` 有變化。擷取期間設 `forceMatrixRecalculationPerRender` 後修正。
   - **依審查修正**：走路位移由 3.46 m 改為 2.65 m，與腳步著地速度 1.06 m/s 一致；環繞段改用 1 倍速；奔跑鏡頭橫向距離固定 4.6 m，避開路旁灌木。近景焦點改為頭骨骨骼。
5. 試渲染（640×360，15 格）目視確認後，完整渲染 300 格並編碼 MP4。

## 已知限制
