## 驗收

1. Blender 每秒 96 次採樣 Walk、Run：實際腳部網格不得低於靜止地面超過 1 mm。
2. 上臂、前臂左右動作相關係數 < -0.9；循環接點無姿勢跳躍，著地腳步配合根節點速度後位移 < 1 mm。
3. FBX 重新匯入確認分件、骨架、動作時長與實際蒙皮運動。
4. Unity 試渲染及正式渲染成功；影片為 1280×720、24 fps、300 格、12.5 秒、H.264，完整解碼通過，抽格目視檢查。
